Entry for the make.fun bounty [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe): a program that writes one line inventing the most useless superpower imaginable. The power sounds handy for half a second — charging a phone just by staring at it — then collapses: it takes exactly as long as the charger, and you have to keep staring the whole time.

The entry text: "I can charge any phone to 100% just by staring at it, but it takes exactly as long as the charger."

## Run it

```sh
python3 main.py
```
